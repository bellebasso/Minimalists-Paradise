# Project Context: Minimalists Paradise

Minimalists Paradise is developed by Isabelle Basso as a "minimal but not too simple" theme for Obsidian.

## Core Philosophy
The theme is built on the idea that a tool should be visually pleasing without being distracting. It uses a "card-based" layout to separate UI elements, creating a sense of organization and depth.

## Target Audience
*   **Aesthetic-Focused Users**: Who want a polished, "Safari-like" look.
*   **Power Users**: Who utilize Style Settings to fine-tune every detail.
*   **Academic/Student Users**: Who rely on callouts (Infobox, Tabbed) for complex note structures.

## Design Priorities
1.  **The Card Layout**: The central visual element.
2.  **Color Schemes**: Providing diverse presets (Onyx, Abyss, Moss, etc.).
3.  **Interactive Feedback**: Hover effects for properties and UI elements (Hider).
4.  **Accessibility**: Ensuring readability across different color schemes.

## Key Differentiators
*   **Safari-style Tabs**: Integrated tab styling that matches the color accent.
*   **Hover Properties**: A unique solution for hiding note properties until needed.
*   **Extended Color Schemes**: Deep integration with Style Settings for switching entire palettes easily.
