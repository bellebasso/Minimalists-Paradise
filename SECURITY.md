# Security Policy

## Supported Versions

Only the latest released version of this theme is actively maintained and supported.

## Reporting a Vulnerability

If you believe you have discovered a security issue related to this repository, please use GitHub's private vulnerability reporting feature or contact the maintainer directly.

Please avoid publicly disclosing potential vulnerabilities until they have been reviewed.

## Scope

This repository contains an Obsidian theme implemented primarily through CSS and metadata files.

Issues related to visual appearance, styling, compatibility, accessibility, or user interface behavior are generally not considered security vulnerabilities and should be reported through the normal issue tracker.

## Security Expectations

This theme does not collect user data, communicate with external services, or execute arbitrary code. Consequently, the scope for security vulnerabilities is limited compared to software projects that process data or execute code.
